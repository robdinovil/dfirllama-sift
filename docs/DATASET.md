## Dataset 1: Synthetic RDP Compromise (`demo/data/tslsm_demo.db`)

| Property | Value |
|----------|-------|
| **Source** | Generated by `demo/generate_demo_data.py` — fully synthetic |
| **License** | MIT (same as this project) |
| **Events** | 1,800 |
| **Format** | SQLite, table `rdp_activity` |
| **Date range** | 2024-01-01 to 2024-06-28 (synthetic) |
| **Event types** | EventId 21/22/23/24 (Terminal Services Local Session Manager) |

### Scenario

Simulates 6 months of RDP activity on `acme-rds01.acmecorp.local` with:
- 6 legitimate users with normal working-hours patterns
- Starting 2024-06-22: attacker IP `102.20.90.8` accessing as `administrator`
- Log clearing event at 2024-06-22 19:45 UTC

### Ground Truth

20 forensic questions with verified SQL in `benchmark/ground_truth.py`. All answers are derivable by running the SQL against `tslsm_demo.db`.

### How It Was Created

```bash
# Downloaded 21 EVTX files from sbousseaden/EVTX-ATTACK-SAMPLES
# Parsed with EvtxECmd (Eric Zimmerman)
dotnet /opt/zimmermantools/EvtxeCmd/EvtxECmd.dll \
  -d demo/real_data/evtx/ \
  --csv demo/real_data/csv/ \
  --csvf real_attack_events.csv

# Loaded into SQLite
python3 -c "
import pandas as pd, sqlite3
df = pd.read_csv('demo/real_data/csv/real_attack_events.csv', encoding='utf-8-sig')
conn = sqlite3.connect('demo/real_data/real_attack.db')
df.to_sql('windows_events', conn, if_exists='replace', index=False)
"
```

### Ground Truth

20 forensic questions with verified SQL in `benchmark/ground_truth_real.py`. All answers calculated directly from `real_attack.db`.
